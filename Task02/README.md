\# Лабораторная работа №2



\## Подготовка скриптов для создания таблиц и добавления данных



\### Назначение



В лабораторной работе реализована подготовка SQL-скрипта для создания базы данных и загрузки данных из исходных файлов.



Для автоматизации используется Python-скрипт `make\_db\_init.py`, который формирует файл `db\_init.sql`.



\### Структура проекта



В каталоге `Task02` находятся:



\- `make\_db\_init.py` — Python-скрипт формирования SQL-скрипта;

\- `db\_init.sql` — SQL-скрипт создания таблиц и добавления данных;

\- `db\_init.bat` — скрипт запуска формирования и заполнения базы данных;

\- `movies\_rating.db` — база данных SQLite;

\- `README.md` — описание лабораторной работы.



Исходные данные находятся в каталоге `dataset`.



\### Структура базы данных



База данных называется `movies\_rating.db` и содержит четыре таблицы:



\- `movies` — информация о фильмах;

\- `ratings` — оценки пользователей;

\- `tags` — теги фильмов;

\- `users` — информация о пользователях.



\### Используемые технологии



Для выполнения лабораторной работы необходимы:



\- Python 3;

\- SQLite 3;

\- Git Bash или другая командная оболочка.
