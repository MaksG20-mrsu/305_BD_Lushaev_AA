\# Task01



\## Структура файлов данных



Каталог `Task01` содержит исходные файлы набора данных MovieLens, а также файлы, созданные в ходе выполнения лабораторной работы.



\- `genres.txt` — список жанров фильмов;

\- `movies.csv` — информация о фильмах, включая идентификатор, название и жанры;

\- `occupation.txt` — список профессий пользователей;

\- `ratings.csv` — оценки фильмов, выставленные пользователями;

\- `tags.csv` — пользовательские теги, присвоенные фильмам;

\- `users.txt` — информация о пользователях;

\- `ratings\\\\\\\_count.txt` — количество оценок для пользователей с минимальным и максимальным идентификаторами;

\- `sqlite.txt` — версия установленной SQLite и список доступных режимов вывода.



\### Структура файла `ratings.csv`



Файл содержит следующие поля:



| Поле | Описание |

|---|---|

| `userId` | идентификатор пользователя |

| `movieId` | идентификатор фильма |

| `rating` | оценка пользователя |

| `timestamp` | время выставления оценки |



Первая строка файла содержит названия столбцов.
